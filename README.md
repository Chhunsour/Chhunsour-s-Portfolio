---

## 🛠️ Tech Stack

- **Framework:** React 18 & TypeScript
- **Styling:** Tailwind CSS & Tailwind Animate
- **Smooth Scrolling:** Lenis Scroll
- **Routing:** React Router DOM
- **Build Tool:** Vite

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
